# Reverse HavenCraft

An **independent, clean-room** third-person settlement-building prototype inspired by the publicly documented game systems of Dionic Software's HavenCraft.

> This is a fan research / gameplay-systems reconstruction project, **not** HavenCraft source code, an official port, or an asset extraction. HavenCraft belongs to its respective creators. Do not copy or distribute proprietary game assets, code, or branding.

## Status

Development starts with a playable Godot 4 prototype on a feature branch. The goal is to validate grid building, material accounting, autonomous villager production, and inspectable job blocking before expanding scope.
